# Data files

The analysis scripts expect the following internship datasets in this folder:

- `stock_prices.csv` — stock-price data used for Level 1 cleaning and the AAPL time-series analysis
- `iris.csv` — Iris flower measurements used for Level 1 EDA
- `house_prediction.txt` — housing data used for Level 2 regression
- `churn_train_80.csv` — training data for Level 3 classification
- `churn_test_20.csv` — testing data for Level 3 classification
- `sentiment.csv` — social-media text data used for Level 3 sentiment analysis

These datasets were supplied for the internship task. They are kept with the final submission package. The analysis code uses relative paths so the files can be placed here and the scripts run from their corresponding level folders.
